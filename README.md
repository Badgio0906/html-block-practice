# HTML ブロック練習（スタッフ向け）

1. `index.html` を**ダブルクリックするだけ**で開きます（Chrome / Edge 推奨）。インストールもネット接続も不要です。
2. 左の部品（`<h1>` などのコードのブロック）の「＋追加」をクリック（またはドラッグ）して並べ、黄色の欄に文字を入力します。右の「画面」に表示結果がすぐ反映されます。右上のタブで「ブラウザ」（表示結果）と「コード」（エディタ風のファイル全体のコード）を切り替えられます。ブロックにマウスを合わせると、コードの該当行も光ります。
3. タグ（`<h1>` など）にマウスを合わせると説明、クリックすると使用例（3パターン）が表示されます。並べる前の部品でも使えます。
4. 練習1〜15 → 確認A・B → タイピング1〜4 の順。
   - 練習11〜15 は「箱ブロック」（`<header>` ページの上部・`<main>` 主な内容・`<footer>` ページの下部）で、ページを大きなまとまりに分ける練習です。箱の開始タグと終了タグの間に、ほかのブロックを入れられます。箱をクリックして選んでから「＋追加」するとその箱の中に入ります（ドラッグや ▲▼ でも出し入れできます）。答え合わせでは、どの箱に何が入っているかまで確認します。
     - 練習11 ページの骨組み（箱を並べる）→ 練習12 共通の部分 → 練習13 間違いを直す（逆の箱に入ったサイト名・連絡先を直す）→ 練習14 箱に入れる → 練習15 箱で組み立て
   - 練習12「共通の部分」では、自分で作ったヘッダー（サイト名）とフッター（連絡先）が「トップ・自己紹介・お問い合わせ」の3ページすべてに出ることを、右の画面の上のタブで切り替えて確かめます（中身＝`<main>` だけがページごとに変わります）。3ページすべてを見ると正解になります。Word のヘッダー・フッターが全ページに出るのと同じ考え方です。
   - 声かけの例：「サイト名を書き換えてから、ほかのページも見てみてください。全部変わりましたか？」
   - 箱を使う練習では、右の画面の「デザインを付ける」（最初からオン）で、実際のサイトのように箱ごとの見た目が付きます（上部＝色の帯、主な内容＝白い枠、下部＝灰色の小さな文字）。違う箱に入れると見た目がおかしくなるので、「なぜ箱に入れるのか」を体験できます。これは CSS（Progate の次の段階）の役割の体験でもあります。
   - 練習11〜15 の正解画面には「なぜこの箱？」の短い解説が出ます。
   - 右の画面の「箱を表示」（ステージを開くたびにオフから始まります）にチェックを入れると、見本と自分の画面の各要素に枠とタグ名が付き、ページの構造（箱の中に箱が入っている形）が見えます。どの練習でも使えます。
   - 声かけの例：「このページは、上部・主な内容・下部のどこに何がありますか？」と、作る前に区切ってもらうと構造の理解が進みます。
   - 確認A・Bとタイピング編は練習10をクリアすると開きます。確認A・B以外は「スキップして次へ」で先に進めます。
   - タイピング編は、Progateに進む前の準備です。タグを自分のキーボードで打ちます（「/」とタグ名 → 終了タグ → 開始・終了タグ → 1行まるごと）。答え合わせをすると各欄に ○ / ✕ が付きます。全角で入力したときは、その旨のヒントが出ます。
5. 「💾 ページを保存」で、並べたページを `.html` ファイルとしてダウンロードできます（練習10の正解画面からも保存可）。保存したファイルをダブルクリックすると、ブラウザで開けます。保存前の画面で、ファイル全体のコード（`<body>` の中に並べたブロックが入ること）も確認できます。
6. 進み具合（★）はそのPCのブラウザに自動保存されます（別のPC・ブラウザには引き継がれません）。最初からやり直すときは、ブラウザの閲覧データ（サイトデータ）を削除してください。
